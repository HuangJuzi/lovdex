两层状态语义

第一层 status（4 列）

状态含义触发方
待办 Todo可以开工，点"开始"它就跑（含原 backlog）手动
进行中 In Progress有一个会话正在真实地干这件事引擎自动
评审 Review会话交付了，等你验收（AI 判定 done 也留在这）引擎自动
完成 Done你确认过了手动

第二层 sub_status（卡片左下角标签）

归属列sub_status文案来源
进行中running会话运行中实时派生
进行中failed执行失败持久化
进行中waiting_answer / waiting_plan / waiting_approval等你回答 / 等你确认计划 / 等你批准实时派生
进行中only_plan / needs_review / blocked计划待执行 / 待你决策 / 需协助AI 判定，持久化
评审pending_acceptance / done待你验收 / 已完成实时派生 / AI 判定

AI 判定行为

⚠ AI 判定写入 sub_status（不是 status）：done 判定任务留在评审列（已完成标签，人 gate 进完成列）； only_plan / needs_review / blocked 判定任务移回进行中列并打对应标签。

进行中列标签（含 AI 判定移回）

in_progress + sub_status: failed 执行失败 (session failed / 启动对账孤儿) running 会话运行中 (默认) waiting_* 等你回答/确认计划/批准 (审批浮层) only_plan 计划待执行 (AI 判定 → 移回进行中) needs_review 待你决策 (AI 判定 → 移回进行中) blocked 需协助 (AI 判定 → 移回进行中)

评审列标签

in_review + sub_status: pending_acceptance 待你验收 (默认，AI 未判定) done 已完成 (AI 判定 done，人验收后进完成列)

注：failed 已持久化（取代旧实时 flag）。后端启动时 reconcile 把"进行中但会话无存活 run"的任务标 failed；重试（running）会清掉 failed。
