描述

opencode 会话在工具调用失败时直接终止 run，用户必须手动重跑整条任务。期望在主进程加一层「最多 1 次」的重试策略，重试前重新注入上下文前缀；远程设备走隧道时跳过重试，避免双跑。

备注

重试上限要可配（默认 1）；重试事件需写入会话时间线，便于复盘。已与 §2.9 计费信任边界确认：重试不重复计费。
